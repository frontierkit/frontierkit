Find out which model and prompt answer your questions best.

FrontierKit runs your questions through every model, prompt and pipeline step you want to compare, scores the answers, and tells you which setup to use. It runs on free model endpoints.

What you can compare

Anything that changes the answer.

Models and vendors

SAIA, NVIDIA, Groq, OpenRouter, Ollama, or any endpoint that speaks the OpenAI chat format. No extra dependencies.

Prompts and context

Prompt templates, with or without reading material, in every combination.

Your own code

Every pipeline step can be a plain Python function: a retriever, a re-ranker, a check on the answer.

Quality, speed and cost

Results show the setups nothing else beats on all three, so you choose the trade-off.

How it works

Three steps from questions to a recommendation.

01

Write your questions

A CSV with questions, reference answers and, if you like, reading material.

question,answer,context
Which organ produces insulin?,pancreas,"Insulin is…"
Largest ocean?,Pacific Ocean|Pacific,"The Pacific…"
02

Run one command

It checks each model, then tries every combination, pacing calls to stay inside free limits.

python examples/pick_models.py \
  --questions my_questions.csv
03

Read the answer

A ranked table, the best setup, and a faster one if it is nearly as good.

Best quality: groq_gpt_oss_20b
  with short+with_context
  (0.92, 292 ms)
Why measure

The model card will not tell you this.

On twelve reading-comprehension questions, the same Gemma model gave equally good answers on two vendors, but one took 230 ms and the other 14.5 seconds. Without reading material its quality fell from 0.95 to 0.10.

Where it stands

An honest status report.

  • Alpha-stage research library, MIT licensed, with about 250 tests.
  • Trying every combination is complete and dependable.
  • For spaces too large to try in full, its search currently finds the best setup in about as many calls as random picking.
  • Pipelines are straight chains of steps; branching pipelines are not searched.
Open source

Built in the open. Contributions welcome.

FrontierKit is MIT licensed and developed on GitHub. Ideas, bug reports and pull requests are all welcome, whatever their size.

How to contribute Open an issue

Add a provider

One row in a table: a base URL, a key name and a default model.

Write a scorer

A function that grades an answer from 0 to 1, for a task the built-in scorers miss.

Share a result

Ran it on your own questions? Tell us what won, and what surprised you.

Improve the search

The open research problem: beat random picking when the space is too large to try in full.

Try it on your own questions.

A free API key and a handful of questions are enough for a first answer.
