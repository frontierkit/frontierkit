Find the setup that answers your questions best. Know how sure you can be.

FrontierKit runs your questions through every model, prompt and pipeline step you want to compare. It tells you which setups are really better and which are too close to call, and lets you check weeks later that your choice still holds.

Three steps

From your questions to a choice that holds.

1. Install

One package. A free key from SAIA, NVIDIA, Groq or OpenRouter is enough to start.

pip install "frontierkit[real]"
2. Compare

Run every combination of prompt, context and model on your own questions.

python examples/pick_models.py --questions my_questions.csv
3. Check it still holds

Run the saved choice again later, by hand or on a schedule.

frontierkit verify decision.json --setup compare.py
Where it stands

An honest status report.

FrontierKit is an alpha-stage research library. Its API may change between minor versions.

  • Dependable today. Trying every combination is complete.
  • Small sets, large gaps. A few dozen questions can only separate large differences, and the output says what it cannot tell apart.
  • Search is not there yet. For spaces too large to try in full, the built-in search finds the best setup in about as many calls as random picking.
  • Straight chains only. Branching pipelines are not searched.
